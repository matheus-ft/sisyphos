# Red-figure icon, draft 2

A second app icon, kept to be improved later: Sisyphos as a heavy-set,
bearded figure in clay, leaning into the stone up a terracotta ground line,
with a meander band beneath, as painted on a vase. The icon in use is the
simpler one in `public/favicon.svg`.

What it still needs: a muscled torso rather than a smooth mass, shaped hands,
the far arm on the stone (it reads as a raised fist), and less empty glaze at
the top left.

`icon.svg` is generated: `node gen.mjs icon.svg` writes it from `scene.mjs`
(`DEBUG=1` adds a grid). To try it as the app icon, copy it over
`public/favicon.svg` and run `node scripts/icons.mjs`.
