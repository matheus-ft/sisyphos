Which muscles are worth distinguishing?

Thirty-seven proposed leaves. Every exercise in the library will reference these ids forever, so this is the decision that is genuinely expensive to change later.

The rule used to draw them: a leaf exists only where a real training decision separates it. Rectus femoris and the vasti split because hip position changes which one works. Vastus lateralis and medialis do not, because no exercise trains one without the other — splitting them would make tagging tedious for no analytical gain.
